Protocol

SourceModuleTarget

A target consisting of a source code module.

protocol SourceModuleTarget : Target

Overview

The module contains either Swift or source files in one of the C-based languages.

Topics

Inspecting a Source Module Target

    The name of the module produced by the target.

    The kind of module, describing whether it contains unit tests, contains the main entry point of an executable, or neither.
