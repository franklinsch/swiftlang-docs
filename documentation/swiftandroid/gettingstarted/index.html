Getting Started

Install the Swift toolchain, Android NDK, and Swift SDK for Android

Overview

Development requires three components:

  1. Swift Toolchain – install with swiftly: swiftly install latest

  2. Android NDK – download from developer.android.com (r27d+ recommended)

  3. Swift SDK for Android – install with swift sdk install (see swift.org)

Hello World

$ swift package init --type executable
$ swift build --swift-sdk aarch64-unknown-linux-android28
$ adb push .build/aarch64-unknown-linux-android28/debug/HelloWorld /data/local/tmp/
$ adb shell /data/local/tmp/HelloWorld
Hello, world!
