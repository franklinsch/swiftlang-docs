Discussion

A note on Codable IDs

If this type is Codable, then any distributed actor using this ActorID as its id will gain a synthesized Codable conformance which is implemented by encoding the ID. The decoding counter part of the Codable conformance is implemented by decoding the ID and passing it to the resolve(id:using:) method.
