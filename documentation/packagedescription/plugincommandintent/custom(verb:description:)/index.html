A custom command plug-in intent.

  • macOS
  • SwiftPM 5.6+
case custom(
    verb: String,
    description: String
)

Parameters

verb

The invocation verb of the plug-in.

description

A human readable description of the plug-in’s role.

Discussion

Use this case when none of the predefined cases fulfill the role of the plug-in.
