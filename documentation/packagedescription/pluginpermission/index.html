PluginPermission

The type of permission a plug-in requires.

  • macOS
  • SwiftPM 5.6+
enum PluginPermission

Overview

Supported types are PluginPermission.allowNetworkConnections(scope:reason:) and PluginPermission.writeToPackageDirectory(reason:).
