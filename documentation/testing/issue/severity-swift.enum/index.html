Enumeration

Issue.Severity

An enumeration representing the level of severity of a recorded issue.

  • Swift 6.3+
  • Xcode 26.4+
enum Severity

Overview

The supported levels, in increasing order of severity, are:

  • Issue.Severity.warning

  • Issue.Severity.error

Topics

Enumeration Cases

  • case error

    The severity level for an issue which represents an error in a test.

  • case warning

    The severity level for an issue which should be noted but is not necessarily an error.
