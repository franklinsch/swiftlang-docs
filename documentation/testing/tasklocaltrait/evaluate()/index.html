evaluate()

Evaluate this trait’s bound value.

  • Swift 6.5+
  • Xcode 16.0+
func evaluate() async throws -> Value

Return Value

The result of invoking the value closure passed to taskLocal(_:withValue:).

Discussion

Throws

Whatever is thrown when invoking the value closure passed to taskLocal(_:withValue:).

Each call to this function invokes the closure that was passed to taskLocal(_:withValue:). The resulting value isn’t cached or stored by this trait, so repeated calls may produce different values or cause side effects to occur more than once.
