Structure

TaskLocalTrait

A type that that binds a task local value for the duration of a test or suite.

  • Swift 6.5+
  • Xcode 16.0+
struct TaskLocalTrait<Value> where Value : Sendable

Overview

When you apply an instance of this trait to a test suite, the testing library recursively applies it to all test suites and test functions within it.

To add this trait to a test, use taskLocal(_:withValue:).
