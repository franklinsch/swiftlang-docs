Initializer

init(_:)

Creates a C++ map containing the elements of a Swift Dictionary.

init(_ dictionary: Dictionary<Self.Key, Self.Value>) where Self.Key : Hashable

Discussion

This initializes the map by copying every key and value of the dictionary.

Complexity

O(n), where n is the number of entries in the Swift dictionary
