Instance Method

extracting(droppingLast:)

Returns a buffer pointer over all but the specified number of trailing bytes.

@export(implementation) @safe
func extracting(droppingLast k: Int) -> UnsafeMutableRawBufferPointer

Parameters

k

The number of bytes to drop off the end of the buffer. k must be greater than or equal to zero.

Return Value

A buffer pointer leaving off the specified number of trailing bytes.

Discussion

If the number of bytes to drop exceeds the number of bytes in the buffer, the result is an empty buffer.

Complexity

O(1)
