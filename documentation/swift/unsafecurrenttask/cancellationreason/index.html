Instance Property

cancellationReason

The reason for the current task’s cancellation, or nil if the task is not cancelled.

  • iOS 9999.0+
  • iPadOS 9999.0+
  • Mac Catalyst 9999.0+
  • macOS 9999.0+
  • tvOS 9999.0+
  • visionOS 9999.0+
  • watchOS 9999.0+
@export(implementation)
var cancellationReason: CancellationError.Reason? { get }

Discussion

Mirrors isCancelled: once this returns non-nil it will consistently return the same value for the remaining life of the task. Not affected by cancellation shields.

Unlike the static cancellationReason property, this property doesn’t reflect a cancellation that only applies to a part of the task, such as an expired deadline of withDeadline(in:tolerance:clock:operation:).
