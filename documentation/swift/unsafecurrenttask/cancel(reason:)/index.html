cancel(reason:)

Cancel the current task, recording a specific CancellationError.Reason.

@export(implementation)
func cancel(reason: CancellationError.Reason)

Discussion

Semantically identical to cancel(), but the passed reason is stored on the task and can be read back via cancellationReason or cancellationReason. First-cancel-wins on the reason: if the task is already cancelled, this call is a no-op with respect to both the cancelled state and the recorded reason.

Child tasks recursively cancelled as a result of this call inherit the same reason.
