Instance Property

id

A stable ID for this task.

  • iOS 9999.0+
  • iPadOS 9999.0+
  • Mac Catalyst 9999.0+
  • macOS 9999.0+
  • tvOS 9999.0+
  • visionOS 9999.0+
  • watchOS 9999.0+
@export(implementation)
var id: Task<Success, Failure>.ID { get }

Discussion

This ID is quick to obtain and can be used to reliably identify a task, instead of its memory address which may be reused once the task has been destroyed. No guarantees are made about its exact numeric value.

The same ID is visible in tools such as swift-inspect and Instruments, which makes it a convenient correlation key for tracing and logging.
