Type Method

checkCancellation()

Throws an error if the task was canceled.

  • iOS 13.0+
  • iPadOS 13.0+
  • Mac Catalyst 13.0+
  • macOS 10.15+
  • tvOS 13.0+
  • visionOS 1.0+
  • watchOS 6.0+
static func checkCancellation() throws

Discussion

The error is always an instance of CancellationError. Its reason reports why the task was cancelled: for example, .deadlineExpired when the current call site is inside a withDeadline block whose deadline has elapsed; .unspecified otherwise.
