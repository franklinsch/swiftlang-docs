extracting(_:)

Constructs a new span over all the elements of this span.

  • iOS 12.2+

@export(implementation)
func extracting(_: UnboundedRange) -> Span<Element>

Return Value

A Span over all the elements of this span.

Discussion

The returned span’s first element is always at index 0. Extracted spans do not share their indices with the span from which they are extracted.

Complexity

O(1)
