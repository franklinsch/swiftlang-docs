pi

The mathematical constant pi (π), approximately equal to 3.14159.

static var pi: Float16 { get }

Discussion

When measuring an angle in radians, π is equivalent to a half-turn.

A type that conforms to the FloatingPoint protocol provides the value for pi at its best possible precision.

In older versions of the standard library (prior to Swift 6.5), this value was documented to be rounded toward zero, rather than to nearest. This was revised in SE-0552 Rounding of Float.pi (note that the only concrete type in the standard library for which this distinction matters is Float).

print(Double.pi)
// Prints "3.141592653589793"
