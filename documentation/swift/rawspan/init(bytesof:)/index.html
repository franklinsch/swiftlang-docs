init(bytesOf:)

Create a span over the bytes of a single value.

@export(implementation)
init<Element>(bytesOf value: borrowing Element) where Element : ConvertibleToBytes

Parameters

value

a value to be borrowed by the span

Discussion

The span has a byteCount of MemoryLayout<Element>.size, and borrows value.
