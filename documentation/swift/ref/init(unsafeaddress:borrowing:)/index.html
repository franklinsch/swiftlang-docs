Initializer

init(unsafeAddress:borrowing:)

Unsafely initializes an instance of Ref using the given ‘unsafeAddress’ as the reference based on the borrowed lifetime of the given ‘owner’ argument.

  • iOS 8.0+
  • iPadOS 8.0+
  • Mac Catalyst 13.0+
  • macOS 13.0+
  • tvOS 9.0+
  • visionOS 1.0+
  • watchOS 2.0+
@unsafe @export(implementation)
init<Owner>(
    unsafeAddress pointer: UnsafePointer<Value>,
    borrowing owner: borrowing Owner
) where Owner : ~Copyable, Owner : ~Escapable

Parameters

pointer

The address to use to reference an instance of type Value.

owner

The owning instance that this Ref instance’s lifetime is based on.
