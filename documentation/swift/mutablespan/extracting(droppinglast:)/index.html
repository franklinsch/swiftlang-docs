Instance Method

extracting(droppingLast:)

Returns a span over all but the specified number of trailing elements.

  • iOS 12.2+
  • iPadOS 12.2+
  • Mac Catalyst 12.2+
  • macOS 10.14.4+
  • tvOS 12.2+
  • visionOS 1.0+
  • watchOS 5.2+
@export(implementation)
mutating func extracting(droppingLast k: Int) -> MutableSpan<Element>

Parameters

k

The number of elements to drop off the end of the span. k must be greater than or equal to zero.

Return Value

A span leaving off the specified number of trailing elements.

Discussion

If the number of elements to drop exceeds the number of elements in the span, the result is an empty span.

The returned span represents a mutation of this span.

Complexity

O(1)
