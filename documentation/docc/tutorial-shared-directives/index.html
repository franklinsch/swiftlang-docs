Shared Directives

Directives supported by multiple directives in interactive tutorials.

Topics

Content Directives

  • @Chapter(name: String)

    Organizes related tutorial pages into a chapter on a table of contents page.

  • @Intro(title: String)

    Displays an introduction section at the top of a table of contents or tutorial page.

Media Directives

  • @Image(source: ResourceReference, alt: String)

    Displays an image in a tutorial.

  • @Video(source: ResourceReference, alt: String, poster: ResourceReference)

    Displays a video in a tutorial.
