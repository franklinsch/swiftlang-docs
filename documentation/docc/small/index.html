Directive

Small

A directive for specifying small print text like legal, license, or copyright text that should be rendered in a smaller font size.

  • Swift-DocC 5.8+
@Small {
    ...
}

Overview

The @Small directive is based on HTML’s small tag (<small>). It supports any inline markup formatting like bold and italics but does not support more structured markup like Row and Column.
