Directive

TopicsVisualStyle

A directive for specifying the style that should be used when rendering a page’s Topics section.

  • Swift-DocC 5.8+
@TopicsVisualStyle(_ style: Style)

Parameters

style

The specified style that should be used when rendering a page’s Topics section. (required)

  • term list: A list of the page’s topics, including their full declaration and abstract.

  • term compactGrid: A grid of items based on the card image for each page.

    Includes each page’s title and card image but excludes their abstracts.

  • term detailedGrid: A grid of items based on the card image for each page.

    Unlike compactGrid, this style includes the abstract for each page.

  • term hidden: Do not show child pages anywhere on the page.
