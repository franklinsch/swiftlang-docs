API Collection

swift sdk

Perform operations on Swift SDKs.

  • Swift 6.1+

Overview

By default, Swift Package Manager compiles code for the host platform on which you run it. Swift 6.1 introduced SDKs (through SE-0387) to support cross-compilation.

SDKs are tightly coupled with the toolchain used to create them. Supported SDKs are distributed by the Swift project with links on the installation page for macOS and Linux, and included in the distribution for Windows.

Additionally, the Swift project provides the tooling repository swift-sdk-generator that you can use to create a custom SDK for your preferred platform.

Topics

Installing an SDK

  • swift sdk install

    Installs a given Swift SDK bundle to a location discoverable by SwiftPM.

Listing SDKs

  • swift sdk list

    Print a list of IDs of available Swift SDKs available on the filesystem.

Removing an SDK

  • swift sdk remove

    Removes a previously installed Swift SDK bundle from the filesystem.

Configuring an SDK

  • swift sdk configure

    Manages configuration options for installed Swift SDKs.

Deprecated Commands

  • swift sdk configuration set

    Sets configuration options for installed Swift SDKs.

  • swift sdk configuration show

    Prints all configuration properties currently applied to a given Swift SDK and target triple.

  • swift sdk configuration reset

    Resets configuration properties currently applied to a given Swift SDK and target triple. If no specific property is specified, all of them are reset for the Swift SDK.
