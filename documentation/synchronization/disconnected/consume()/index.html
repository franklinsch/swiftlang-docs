Instance Method

consume()

Consumes the wrapper and returns the wrapped value.

  • iOS 9999.0+

@export(implementation)
consuming func consume() -> sending Value

Return Value

The previously wrapped value, in a disconnected region.

Discussion

The returned value is in a disconnected region, so you can transfer it across an isolation boundary:

let wrapper = Disconnected(Resource())
let resource = wrapper.consume()
// `resource` can now be sent to another isolation region.

After consume() returns, the wrapper has been consumed and no further operations on it are possible.
