Initializer

init(_:)

Creates a disconnected wrapper around the given value.

  • iOS 9999.0+
  • iPadOS 9999.0+

@export(implementation)
init(_ value: consuming sending Value)

Parameters

value

The value to wrap. The wrapper takes ownership of it.

Discussion

The argument is required to be in a disconnected region at the call site. A freshly constructed value with no aliases satisfies this requirement directly:

final class Resource: ~Sendable {}
let wrapper = Disconnected(Resource())
