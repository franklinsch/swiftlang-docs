withValue(body:)

Calls body with mutable access to the wrapped value.

@export(implementation)
mutating func withValue<Return, Failure>(body: (inout sending Value) throws(Failure) -> Return) throws(Failure) -> Return where Failure : Error, Return : ~Copyable

Parameters

body

A closure that receives inout sending access to the wrapped value.

Return Value

The value returned by body.

Discussion

The closure receives the value as inout sending, so within the closure scope the value can be transferred to another isolation region. The wrapper is required to hold a disconnected value once body returns.

var wrapper = Disconnected([1, 2, 3])
wrapper.withValue { array in
    array.append(4)
}

If body throws, the wrapper retains whatever value the closure last left in storage and the error propagates to the caller.

Throws

Any error thrown by body.
