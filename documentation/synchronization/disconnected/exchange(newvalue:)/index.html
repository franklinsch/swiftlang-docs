Instance Method

exchange(newValue:)

Replaces the wrapped value with a new value and returns the previous one.

@discardableResult @export(implementation)
mutating func exchange(newValue: consuming sending Value) -> sending Value

Parameters

newValue

The replacement value.

Return Value

The previously wrapped value, in a disconnected region.

Discussion

newValue is required to be in a disconnected region. The previously stored value is returned and is in a disconnected region:

var wrapper = Disconnected(Resource())
let old = wrapper.exchange(newValue: Resource())
// `old` can now be sent to another isolation region.
