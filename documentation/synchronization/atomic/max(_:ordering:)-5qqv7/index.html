Instance Method

max(_:ordering:)

Perform an atomic maximum operation and return the old and new value, applying the specified memory ordering.

@discardableResult @export(implementation)
func max(
    _ operand: UInt128,
    ordering: AtomicUpdateOrdering
) -> (oldValue: UInt128, newValue: UInt128)

Parameters

operand

An integer value.

ordering

The memory ordering to apply on this operation.

Return Value

A tuple containing the original value before the operation and the new value after the operation.
