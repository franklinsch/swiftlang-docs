demangle(_:)

Given a mangled Swift symbol, demangle it into a human readable format.

func demangle(_ mangledName: String) throws(DemanglingError) -> String

Parameters

mangledName

A mangled Swift symbol.

Return Value

A human readable demangled Swift symbol.

Discussion

If the provided string is not a valid mangled swift identifier this function will throw. If mangling succeeds the returned string will contain a demangled human-readable representation of the identifier.

Throws

When the demangling fails for any reason.

Warning

The demangled output is lossy is not not guaranteed to be stable across Swift versions. Future versions of Swift may choose to print more (or less) information in the demangled format.
