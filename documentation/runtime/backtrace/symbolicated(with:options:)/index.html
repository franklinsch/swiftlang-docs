Instance Method

symbolicated(with:options:)

Return a symbolicated version of the backtrace.

  • macOS 13.0+
func symbolicated(
    with images: ImageMap? = nil,
    options: Backtrace.SymbolicationOptions = .default
) -> SymbolicatedBacktrace?

Discussion

  • images: Specifies the set of images to use for symbolication. If nil, the function will look to see if the Backtrace has already captured images. If it has, those will be used; otherwise we will capture images at this point.

  • options: Symbolication options; see Backtrace.SymbolicationOptions.
