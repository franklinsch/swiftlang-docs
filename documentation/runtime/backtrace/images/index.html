Instance Property

images

A list of captured images.

  • macOS 13.0+
var images: ImageMap?

Discussion

Some backtracing algorithms may require this information, in which case it will be filled in by the capture() method. Other algorithms may not, in which case it will be nil and you can capture an image list separately yourself using ImageMap.capture().
