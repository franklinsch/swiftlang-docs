Instance Property

uniqueID

The unique ID of the image, as a byte array (note that the exact number of bytes may vary, and that some images may not have a unique ID).

  • macOS 13.0+
var uniqueID: [UInt8]? { get }

Discussion

On Darwin systems, this is the LC_UUID value; on Linux this is the build ID, which may take one of a number of forms or may not even be present.
