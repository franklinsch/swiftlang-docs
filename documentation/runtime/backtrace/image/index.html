Instance Properties

  • var name: String?

    The name of the image (e.g. libswiftCore.dylib).

  • var path: String?

    The full path to the image (e.g. /usr/lib/swift/libswiftCore.dylib).

  • var uniqueID: [UInt8]?

    The unique ID of the image, as a byte array (note that the exact number of bytes may vary, and that some images may not have a unique ID).
