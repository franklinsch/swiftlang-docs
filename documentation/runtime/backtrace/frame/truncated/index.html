Backtrace.Frame.truncated

Indicates a discontinuity of unknown length.

  • macOS 13.0+
case truncated

Discussion

This can only be present at the end of a backtrace; in other cases we will know how many frames we have omitted. For instance,

0: frame 100 <—– bottom of call stack 1: frame 99 2: frame 98 3: frame 97 4: frame 96 5: … <—– truncated
